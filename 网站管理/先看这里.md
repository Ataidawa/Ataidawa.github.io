# 网站管理入口

日常只改这个文件夹。Hexo 启动或生成时自动同步，不需要再到源码目录找文件。

| 操作 | 位置 |
| --- | --- |
| 新文章 | 文章/文章名/文章名.md；素材放同目录的文章名.assets/ |
| 新作品 | 作品/英文文件名.md；类别写作品/分类.yml已有名称 |
| 相册图片与说明 | 相册/相册.yml |
| 添加友链 | 友链/友链.yml |
| 首页姓名、介绍、头像 | 设置/首页.yml 中 profile |
| 固定状态灯与自定义方向 | 设置/首页.yml 的 profile.status 与 profile.specialty |
| 网站 Logo | 替换素材/logo.svg，或修改设置/首页.yml的logo_image.image_path |
| 网站配色、圆角、动效变量 | 设置/配色与外观.css顶部的:root与深色模式变量 |
| 全局歌单 | 设置/播放器.yml中的playlist |
| QQ、微信、邮箱、电话 | 设置/页脚.yml中的contacts |
| 图片与其他上传素材 | 素材/；网页地址使用/managed-assets/文件名 |

## 使用步骤

1. 在这里修改文件并保存。
2. 运行项目根目录的 `npm run build` 生成，或重新启动 `npm run server` 预览。仅修改这个管理文件夹时，预览服务不会自动监听，需要重新生成或重启。
3. 刷新浏览器。修改不自动发布 GitHub。

源目录的对应 Markdown、数据和外观文件是自动同步副本，请不要同时编辑两处。文章与作品文件名全站唯一；删掉管理文件夹中的 Markdown 后，下一次生成会清理对应的自动副本。主题源文件、模板和脚本仍在原项目位置，日常无需修改。

## 两篇操作手册

- 文章/website-operation-guide/website-operation-guide.md：维护参数、文章、作品、相册和友链的完整示例。
- 文章/component-guide/component-guide.md：提示块、折叠、选项卡、按钮、图片、音乐和代码的写法。

正文目录、友链、相册、控件以及设计规范，都可以在本地网页中查看实际效果。

状态灯：seeking 求职中（蓝）、available 开放合作（绿）、employed 在职（琥珀）、unavailable 暂不接单（灰）。specialty 是自由填写的方向文字。

旧站内容已导入：文章含随笔汇总、相册和友链仍在上表对应目录维护。迁移详情见“导入记录.md”；引用的旧素材集中在“素材/legacy/”。原始“待整理”文件夹已按要求在导入后删除。

## Typora 写作

文章已调整为“一篇一个目录”：`文章/文章名/文章名.md` 与 `文章名.assets/` 放在一起。原有文章已迁移，本地引用图片和音频不必写站点绝对路径。Typora 图像偏好设为复制到 `./${filename}.assets` 并优先使用相对路径即可。新文章可从“模板/文章模板.md”复制，操作手册已同步更新。
