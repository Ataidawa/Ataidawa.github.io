所有日常维护文件都放在项目根目录的 **网站管理** 文件夹。Hexo 启动或生成时会读取这些文件，源目录里的对应文件是自动副本。

## 快速找到操作位置

| 想做什么 | 编辑哪里 |
| --- | --- |
| 发文章 | 网站管理/文章/文章名/文章名.md |
| 加作品 | 网站管理/作品/*.md |
| 管理作品类别 | 网站管理/作品/分类.yml |
| 管理相册簿 | 网站管理/相册/相册.yml |
| 添加友链 | 网站管理/友链/友链.yml |
| 改首页简介与求职状态 | 网站管理/设置/首页.yml |
| 改 Logo | 网站管理/素材/logo.svg |
| 改全站色系与圆角 | 网站管理/设置/配色与外观.css |
| 改全局播放器歌单 | 网站管理/设置/播放器.yml |
| 改联系方式 | 网站管理/设置/页脚.yml |

## 添加文章 Markdown

在“文章”文件夹新建英文文件名的 Markdown。文件开头填写标题、日期、分类，分类必须为“文章”。下面的标题“文章标题”和正文可自由替换。

```yaml
---
title: 文章标题
date: 2026-11-15 12:00:00
categories:
  - 文章
tags:
  - 设计
---
```

分隔线后写正常 Markdown：段落、二级标题、列表、图片、代码块等。英文文件名决定默认文章地址，例如 `my-note.md` 对应 `/posts/my-note/`。文章与作品不要使用相同文件名。

## 添加作品集内容

在“作品”文件夹新建 Markdown。类别使用“作品/分类.yml”中的名称。封面推荐保持原有 4:5 构图，首页缩览会裁成方形。作品正文按背景、问题、做法、结果组织。

```yaml
---
title: 新作品标题
date: 2026-11-15 12:00:00
categories:
  - 主图设计
featured_image: /managed-assets/my-project.jpg
---
```

把 `my-project.jpg` 放进“素材”文件夹。网页地址写 `/managed-assets/my-project.jpg`，不要写电脑磁盘路径。

## 添加相册照片

编辑“相册/相册.yml”，照片实际文件放在“素材”。`placeholder` 为 true 表示占位预览，换真实照片后设为 false。

```yaml
- title: 日常观察
  description: 城市、色彩与设计灵感。
  placeholder: false
  photos:
    - image: /managed-assets/city.jpg
      caption: 杭州的一次散步
```

## 添加友链

在“友链/友链.yml”末尾增加一组。备注可以用 `|` 写多行。头像不填写时显示名称首字。

```yaml
- name: 朋友的名字
  url: https://example.com
  avatar: /managed-assets/friend.jpg
  description: |
    这里写我的备注
    或者对方的网站签名
```

## 修改首页与求职状态

编辑“设置/首页.yml”。`profile.status` 选择固定状态，`profile.specialty` 填写方向，`title` 是姓名，`role` 是职位与城市，`body` 是多段介绍，`image` 是头像地址。

```yaml
profile:
  status: available
  specialty: 电商视觉设计
  title: 周城栋
  role: 电商视觉设计师 · 杭州
  body: |
    第一段介绍。
    第二段介绍。
  image: /managed-assets/my-photo.jpg
  links:
    查看作品: /work/
    查看文章: /notes/
logo_image:
  enable: true
  image_path: /managed-assets/logo.svg
```

## 更换 Logo 与配色

直接替换“素材/logo.svg”即可更新 Logo。若使用 PNG，放入“素材”并修改 `logo_image.image_path`。现有 Logo 深色时会反白，建议保留单色标志。

“设置/配色与外观.css”顶部集中列出颜色与圆角变量。浅色改 `:root`，深色改 `[data-theme="dark"]`。常改的是 `--accent`、`--on-accent`、`--selected`、`--hover`、`--bg`、`--surface`。改变强调色时应同时检查强调色上的文字对比度。

圆角使用 `--radius-card`、`--radius-panel`、`--radius-control` 等变量。不要批量替换正文里出现的所有 px 数字。

## 更换音乐歌单

编辑“设置/播放器.yml”，替换 `playlist` 的网易云链接；`enabled` 控制是否显示。`api` 是兼容 Meting 的解析服务接口，接口失效才需要更换。

```yaml
enabled: true
playlist: https://music.163.com/playlist?id=17851162134
api: https://api.injahow.cn/meting/
```

歌曲版权、接口可用性会影响播放，部分音源只能试听。文章内音乐使用独立的链接参数，调用同一个全局播放器。

## 预览与删除

保存后运行 `npm run build`，再刷新本地网页，或重启预览服务。管理文件夹目前不会被预览服务自动监听。修改不会自动推送 GitHub。

删除管理文件夹中的文章或作品后，下一次生成会删除对应自动副本。图片等素材不会自动删除，避免误删仍被其他内容引用的文件。

## 首页状态灯

修改“设置/首页.yml”中的 `profile.status` 选择固定状态，`profile.specialty` 单独填写方向，不再编辑整段 badge 文字。

| status 参数 | 固定文字 | 状态灯 |
| --- | --- | --- |
| seeking | 求职中 | 蓝色 |
| available | 开放合作 | 绿色 |
| employed | 在职 | 琥珀色 |
| unavailable | 暂不接单 | 灰色 |

例如 `status: available` 配合 `specialty: 品牌视觉设计`，显示“开放合作 · 品牌视觉设计”。方向留空只显示状态。修改后重新生成或重启预览服务。

## 首页预览与同步说明

首页会自动选取相册中前 3 张照片、友链中前 2 项作为局部展示，调整相册或友链文件中的顺序即可改变展示内容。相册图片保留大图预览，友链跳转新窗口。

目前首页导航、页面布局、脚本属于程序部分，不在首页参数文件中调整。`首页.yml` 只提供简介、状态、头像、Logo 和首页操作链接，避免将参数入口与程序结构混淆。配色文件是完整 CSS，优先只改顶部变量；同一变量后文再次赋值时，以最后生效规则为准。

## 全站字体

本站统一采用本地 Noto Sans SC 可变字体，支持 100–900 字重。正文 400、控件 500、标题 600、强调 700；代码区域保留等宽字体。修改“设置/配色与外观.css”末尾的 `--font-sans` 和 `--weight-*` 可以统一调整。

字体文件与授权位于“素材/fonts/noto-sans-sc/”。字体使用 SIL OFL 1.1，支持商业项目的使用与网页嵌入，分发时保留 OFL.txt，不将字体文件单独出售。已转换为 31 个 WOFF2 Unicode 字符包，总计约 9.45 MB（原 TTF 17.77 MB），浏览器按需下载，通常只需其中少量分包。保留全部 30,890 个字符与 100–900 可变字重，使用 font-display:swap。原始 TTF 仅作维护备份，不发布到网站。

### 字库覆盖与生僻字

当前实际文件的 Unicode 映射实测为 30,890 个字符，其中 CJK 区间约 27,778 个字符；不是覆盖全部 Unicode 汉字的字库。抽查“龘、靐、齉、𰻞”有字形，“𠮷”没有。缺字会依次使用系统回退字体；目标设备也缺字时仍可能显示方框。MiSans 主库与 MiSans L3 扩展库需分别比较，不能直接把整个字库家族与单个字体文件作等量比较。大量姓名、古籍生僻字的使用场景需要再搭配授权允许网页分发的扩展字库。

## 品牌名称与图标

“设置/首页.yml”的 `site.title` 控制标签页站点名称，`site.author` 控制页脚署名，`profile.title` 控制首页名称。当前站点标题与页脚署名为 Jopolis.，首页姓名为周城栋。`favicon` 指向“素材/favicon.svg”，Logo 指向“素材/logo.svg”；更换浏览器图标后可增加 URL 版本参数避免旧缓存。

控件投影采用强调色的低透明度衍生色；黑色背景遮罩与图片文字可读性阴影属于独立用途，不作为控件投影处理。

### Logo 与姓名分开设置

左上角使用取景框＋Jopolis. 字标，加载后每约 12 秒自动播放一次短 glitch 效果，不依赖悬停；减少动态效果时停用。首页姓名 `profile.title` 为“周城栋”，标签页站点名 `site.title` 仍为“Jopolis.”，两者互不影响。标签页小图标采用相同的取景框＋J，并独立配置。

Logo 自动 glitch 的间隔在“设置/配色与外观.css”末尾 `brand-ambient-glitch 12s` 中调整，数字越大越安静。减少动态效果时停止自动动画。

## 自动短链接

新文章和作品保存后，首次生成会在 Markdown 开头写入 `short_id`（8 位十六进制 ID），正式地址为 `/p/ID/`。修改标题不影响地址；重命名文件时保留 short_id 即可，复制文章作为新内容时请删除复制来的 short_id，让系统重新生成。重复 ID 会阻止构建，避免覆盖页面。

旧的 `/posts/文件名/` 路径继续生成完整页面，已有分享和手册链接可继续使用；旧站 abbrlink 数字地址若需要全部兼容，需额外导入旧站 ID 对照表，当前没有自动猜测旧 ID。

源码在 main 分支，GitHub Actions 从 main 构建并部署 Pages；gh-pages 保留静态发布快照。修改源码后应提交 main，Pages 设置中的 Source 使用 GitHub Actions。

## 歌单内容更新

网易云歌单增删歌曲后，全局播放器自动重新获取，不再提供手动刷新或恢复默认位置按钮。页面可见时每 5 分钟检查一次；返回页面或展开列表时，距离上次同步超过 1 分钟也会检查。刷新时保留当前音源、播放状态和进度；若当前歌曲已从歌单删除，会暂时保留在本次播放队列，让它正常播放完。

浏览器请求绕过本地 HTTP 缓存，但第三方 Meting 服务仍可能缓存上游数据，因此不能保证网易云更改后立即同步。若仍是旧列表，应检查实时元数据服务或等待上游缓存更新。

### 歌单实时元数据接口

默认列表接口已改为 `https://ataidawa-github-io.vercel.app/api/playlist`，对应仓库的 `api/playlist.js`。它在 Vercel 读取网易云当前歌单，不缓存列表，解决第三方 Meting 的列表陈旧问题；音频 URL 仍由原 Meting 服务解析。接口是公开元数据接口，不需要填写密码或密钥。

GitHub Pages 为纯静态站，会跨域调用这个 Vercel 接口，因此其可用性仍依赖 Vercel 和网易云。将来迁移 EdgeOne 时需要同时迁移此函数或更换等价元数据服务，仅上传 public 不包含服务端函数。音频本身的版权与可播放性不受此修改改变。

播放器在首次歌单加载成功前隐藏，成功后淡入；上次主动隐藏时只显示音乐入口。初次失败每 30 秒后台重试，不弹出空白控件。保留拖动和位置记忆，移除恢复位置与手动刷新按钮。


### WOFF2 字体文件维护

入口仍为 `网站管理/素材/fonts/noto-sans-sc/`：`font.css` 声明分包范围，`woff2/` 存放字体，`subsets.json` 记录覆盖和大小，`OFL.txt` 保留授权。正常写文章无需重新生成，生僻字包也会按需加载。不要单独删除分包。

只有替换字体源文件或重新优化分组时才需要运行 `tools/build_font_subsets.py`。需要 Python 与 fonttools、brotli、zopfli（本地依赖放在 `.runtime/font-tools`）。脚本验证所有原有字符和可变字重轴。运行后再执行正常网站构建。


## 旧站内容迁移后的维护

原有 7 篇文章和《随笔记 · 2024—2025》已经整理到 `网站管理/文章/`。原发布日期和 abbrlink 均保留；日常分享使用自动生成的 `/p/xxxxxxxx/`，旧的 `/posts/数字.html`、`/posts/数字/` 与 `/数字/` 同时兼容。旧 `/essays/`、`/masonry/`、`/links/` 分别兼容随笔汇总、相册和友链。

文章与相册使用的旧图片、声音和早期播放器作品集中在 `素材/legacy/`。相册修改 `相册/相册.yml`，友链修改 `友链/友链.yml`；友链的 `category` 保存旧站分组。外站头像失效时自动显示名字首字。

迁移范围与清理记录见 `网站管理/导入记录.md`。根目录“待整理”在导入完成后已删除。旧教程标记为历史记录，当前网站维护请使用本手册。


### 手机端播放器与备用歌单

播放器先读取同站点 `素材/music/playlist.json`，数据准备好后显示；再在后台请求实时歌单。国内网络无法连接 Vercel 时，仍可显示最近发布的歌单。实时接口恢复后会尝试更新，后台刷新不会重置当前播放进度。实际音频仍依赖外部音源。

`npm run build` 会先运行 `tools/update-playlist.cjs`，尝试更新备用歌单；接口失败时保留现有数据并继续构建。更改歌单仍修改 `设置/播放器.yml` 后构建。兼容了不支持 AbortSignal.timeout 的移动浏览器。


## Markdown 与素材放在一起（Typora）

文章采用“一篇一个文件夹”：

```text
网站管理/文章/我的文章/
  我的文章.md
  我的文章.assets/
    配图.png
    录音.m4a
```

Markdown 写 `![配图](我的文章.assets/配图.png)` 即可本地预览，音频可写 `<audio controls preload="metadata" data-title="现场录音" src="我的文章.assets/录音.m4a"></audio>`。文件名有空格时让 Typora 自动转义路径，或使用 `%20`。

在 Typora 的偏好设置 → 图像中，将插入图片设为复制到 `./${filename}.assets`，启用“优先使用相对路径”，并对本地图片、剪贴板图片启用该规则。先保存 Markdown，再粘贴或拖入图片。已迁移的文章也各自设置了 `typora-copy-images-to` 字段，直接指向旁边的素材文件夹。

也可以用菜单“格式 → 图像 → 插入本地图片时 → 复制图片到指定路径”选择素材目录。Typora 会在文档头部写入 `typora-copy-images-to`。参考 [Typora 官方图片说明](https://support.typora.io/Images/)。

网站构建自动递归读取文章目录，将相对图片、音频、附件和封面路径转换为站点地址；源 Markdown 中保留相对路径，不需要手工写 `/managed-assets/`。短链接 `short_id` 保持不变。代码块里的路径示例不会被改写。文章素材应在自己的目录内，避免使用磁盘绝对路径和跨目录的 `../`。

新建时可复制“网站管理/模板/文章模板.md”到新文章文件夹，改文件名、标题和日期；首次构建会自动写入短链接。Typora 全局复制规则会按实际 Markdown 文件名创建 `.assets` 文件夹。全站 Logo、字体与相册等共享素材继续在“素材”管理。


## 图片自动优化

正常放入原始照片即可。构建生成轻量 WebP 展示图和独立高清图，小图不放大。所有页面的展示候选最大 960 像素宽，屏幕外图片延迟加载；高清图只在点击查看大图后请求，不会悬停预加载。展示质量 86、高清质量 92；原图不覆盖，动画图片和 SVG 保持原样。压缩结果按图片内容缓存。调整参数统一修改“网站管理/设置/图片优化.yml”：display_width、display_quality 控制页面展示，preview_width、preview_quality 控制点击后的高清图。参数变更会自动更新缓存标识。


## 首页动态封面

首页顺序为全屏封面、个人简介、作品／文章／相册／友链速览。封面姓名与方向沿用“设置/首页.yml”，封面布局在主题 pages/profile.ejs，配色动效在“设置/配色与外观.css”。首屏高度随导航栏高度与移动端可视区域调整。Logo glitch 约每 4.8 秒触发，减少动态效果设置会停用动效。歌单接口失败会有限重试，音源失败时尝试网易云公开外链；歌曲下架、权限限制或区域不可用仍可能无法播放。


### 首页第二版与播放器收纳

封面调整为中文视觉标题与三张浮动领域卡片；进入作品打开作品页，认识我滚动到个人简介。播放器每次进入先展示约 6 秒，之后自动收纳，点击圆形按钮可展开；播放时圆形封面缓慢旋转，封面失败则使用音乐符号。每次打开回到右下角，不再恢复可能过期的拖动坐标。Logo glitch 提高到约 3.8 秒一次。


### 交互动效更新

播放器展开与收纳使用约 480ms 的双向形变动画，向右下角圆形按钮收束；减少动态效果时直接切换。封面在精确鼠标设备上响应指针位置，调整光感、卡片倾斜和分层视差，移出后回正；手机保留按压反馈。Logo 改为横向切片短促错位，不再使用整块模糊抖动。


### 动画冲突修正

播放器采用实际控件的 transform/opacity 弹性动画，取消复制控件与裁剪路径动画，避免与初次入场动画重叠。封面卡片外层负责持续飘动，内层负责指针倾斜；通过页面导航切回首页时，重新播放封面与三张卡片的错峰入场。Logo 使用红青色散、扫描切片与短促水平撕裂。


### 标题与 Logo 动效细化

封面左侧标题增加轻微的持续呼吸飘动与反向鼠标视差，移动通过缓动回正。领域卡片显式继承各自前景色，避免通用链接样式覆盖蓝卡文字与标识。Logo 色散层改用固定扫描区域的红青遮罩，仅动画 transform 与 opacity，取消动画滤镜和每帧裁剪变化。


### 封面卡片切换与音效

卡片在鼠标移入后平滑切换，点击直接进入作品页，不再需要二次点击。手机可横滑切换，下方也保留上一张、下一张按钮。切换音效及其开关已移除。Logo 色散改为主题蓝与浅蓝；首次直接访问首页时也会设置当前导航状态。


封面透视方向已调整为两侧靠近、中心后退的凹面舞台，glitch 的主题蓝错位幅度增大。


### 固定卡片与轻量视差

移除上一张、下一张及自动换位逻辑。卡片保持固定排布，未选中时斜放；悬停转正，按鼠标在卡片内的位置轻微倾斜。外层漂浮与文字呼吸动效持续播放，整体仅使用小幅平移，不再让按钮或标题产生强透视。当前封面独立样式在 source/css/home-cover.css，减少旧版本规则的相互干扰。Logo 主体位于蓝色切片之上，闪断约 0.1 秒。


### 常态漂浮与背景细节

标题和三张卡片分别使用不同相位的持续漂浮，无鼠标输入时也会运动。广角倾斜只作用于标题文字与未选中的卡片，按钮保持平面；选中卡片的外层转正，内层仍提供轻微角落倾斜。背景新增低对比度点阵和缓慢移动的光带，使用 transform 动画，开启减少动态效果时停止运动。


### 自动轮播与透视强度

按最新调整，三张卡片每 4.5 秒自动轮换前景，鼠标进入或键盘聚焦时暂停，离开后继续；封面滚出屏幕或页面切到后台时不推进。无上一张／下一张按钮，也无切换音效。底纹使用更明显的斜向点阵位移与浅色光带，标题、按钮采用局部广角透视与缩放边距。减少动态效果时关闭轮播和底纹运动。


### 背景与前景色修正

移除扫光和斜线纹理，仅保留低对比度点阵。标题缩放与卡片位置预留布局安全边距。蓝色绑定当前前景卡片（is-featured），不再绑定某个固定类别；轮播及鼠标悬停时，蓝色随前景卡片更新。


### 单向轮播与全站细节

轮播固定向左推进，最左卡片隐入后方后从右侧进入，不再以反向横穿方式回位。背景为低对比蓝色云雾流动，取消点阵和扫光。各页标题区与媒体区加入方向不同、幅度不超过约 10px 的滚动视差；减少动态效果时停用。封面局部广角角度增大并缩小投影内容，保留页面内边距。


### 透视平面与轮播衔接

左侧小字、标题和按钮统一放在同一透视平面，右侧卡片组使用相反方向，形成向画面中心收拢的消失方向。标题与按钮字号增大；移动端降低旋转角度。轮播的位置动画仍由外层负责，持续漂浮转交内层，避免轮播结束时 translate 从零跳回漂浮相位。底纹改成两层错峰渐显渐隐的点阵波纹，减少动态效果时停用。


### 鼠标速度与动态细节

反色圆根据鼠标移动速度平滑放大、减速后收小，停下后回到当前页面最小文字字号（最低保留 10px），最大直径约 96px。速度与尺寸均平滑处理，停止后动画自动休眠。点阵波纹向右下移动并渐显渐隐；左侧内容整组透视加大，手机使用较小角度。


### 竖版卡片与暗色配色

封面卡片采用 9:16 的实际盒子比例，宽度随屏幕高度变化，移动端另设尺寸。透视投影仍会产生视觉上的梯形。暗色模式采用深蓝灰背景、灰蓝普通卡片与低饱和钴蓝前景卡片，蓝色继续跟随当前前景状态；全站深色 token 在“设置/配色与外观.css”，封面局部配色在 source/css/home-cover.css。


### 光标尺寸与横版比例修正

反色圆的静止尺寸改为读取鼠标下方文字的字号与屏幕文本行高度，标题上放大、小字上收小，速度放大仍然有效。卡片按最新要求改为 16:9 横版，并使用紧凑网格排版避免文字被裁切，暗色配色保留。


### 封面类别英文

封面横版卡片已放大，英文按类别分别显示，修改“作品/分类.yml”的 english 数组即可调整每行文字，例如主图为 PRODUCT / IMAGERY、详情页为 PRODUCT / DETAILS、店铺为 STOREFRONT / DESIGN。


## 网站收藏 Marked

入口为 `/marked/`，导航栏可直达。统一维护“网站管理/收藏/网站.yml”，每项填写 name、url（完整 https 地址）、category、description、tags（关键词数组）。分类从 category 自动生成，搜索覆盖名称、描述、分类和标签。默认放了 Typora 与 Hexo 两个示例，按需替换。外部网站在新标签页打开，站内切换保留播放器。


卡片悬停位置会连续影响倾斜：中心接近正面，左右最多约 ±11°、上下约 ±9°，通过阻尼逐帧平滑过渡，离开时复位。减少动态效果时关闭倾斜。


Marked 的导航中文名为“网站收藏”，手机导航使用 Remix Icon 的 bookmark-3-line 书签图标，页面地址仍为 /marked/。


网站收藏已根据聊天与旧站文章填入首批 32 个入口，分类为实用软件、字体资源、设计工具、建站开发、部署服务。优先使用品牌官网及作者项目，苹果字体指向官方资源页。继续维护“收藏/网站.yml”，搜索支持备注和关键词；不再只是两个示例。

## 2026-11-17：网站收藏、可用性与图标

网站收藏的唯一内容入口是 `网站管理/收藏/网站.yml`，会生成 `/marked/`；首页仅展示三个收藏，完整页面支持分类和关键词搜索。修改收藏时不用分别修改首页和收藏页。

```yaml
- name: 示例网站
  url: https://example.com/
  category: 实用软件
  description: 在这里补充用途、下载内容或使用备注。
  tags:
    - 工具
  # favicon 可选：使用实际已存在的本地图标文件
  # favicon: /managed-assets/bookmarks/icons/实际文件名.png
```

`favicon` 对应的文件保存在 `网站管理/素材/bookmarks/icons/`，生成时自动同步到站点。图标经过格式转换，最多 64px；前台懒加载，不调用第三方图标聚合接口。删除 favicon 字段或图片读取失败时，会显示名称首字。

导入浏览器书签时，先按地址和名称去重，再检查跳转后的访问状态。明确失效的链接不再展示；本轮按站主要求，也暂时移除了多次直连、代理请求仍超时或被拦截的链接。403 或反爬拦截不等同于永久关站，相关条目留在本地 `.runtime/bookmark-import/访问检查与移除记录.md` 和备份中，需要时可以恢复。检查结果只反映当时的网络环境，不能保证所有地区随时可用。

公司内部资料、账户信息及尚未确认的私人收藏仍放在本地待确认清单，不发布。下载分享、工具和已获准公开的文档可以入库；读不到文件内容时，将 description 写为“说明待补充”，后续直接在 YAML 中填写。Carefree 已按提供的说明修正为“轻尘（Carefree）”PotPlayer 皮肤，而非字体。

跨页面卡片、文字链接、焦点和图片波纹的交互规范见[网站设计规范](/posts/design-guide/)。首页封面顶部新增间距和四角圆角，右下角入口改为“逛逛网站收藏”。

收藏卡片与友链卡片共用相同圆角、浅色提亮和柔和主题色阴影，轻微上浮并根据鼠标位置倾斜；卡片标题不额外加下划线。普通文字超链接统一沿用文章中的蓝色文字、从指针位置展开的 240ms 细下划线动画，不给整块卡片套文字链接效果。
