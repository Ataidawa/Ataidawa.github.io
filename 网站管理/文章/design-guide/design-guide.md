这份规范记录本站目前采用的色彩、排版、控件与动画规则，作为后续调整页面的共同依据。视觉方向以简洁、清晰、响应高效为主；内容区保持安静，浮层通过透色和模糊建立层级。

## 统一入口

日常修改请使用“网站管理/设置/配色与外观.css”；源码中的同名样式为自动同步副本。所有内容维护入口见[网站操作手册](/posts/website-operation-guide/)。

全站设计变量和组件规范的编辑入口为 `网站管理/设置/配色与外观.css`，生成时同步到 `source/css/design-system.css`。`source/css/codex.css` 保留布局及交互样式。修改网站外观时优先调整语义变量，避免为单个页面再增加一套近似颜色。

蓝色用于主要操作、链接、选中状态和键盘焦点。成功、提醒和错误同时配合图标与文字，避免只凭颜色区分。文字选中采用专门的蓝色配色，深色背景保持炭灰；音乐封面上的播放进度使用白色。

首次访问按北京时间 07:00–19:00 使用浅色，其余时间深色；用户手动选择后记住偏好。时间由设备时钟转换到 `Asia/Shanghai`，不依赖时间查询接口。

## 排版与空间

正文、标题和控件采用本地 Noto Sans SC 可变字体，等宽内容采用本地 Roboto Mono。文章正文最大宽度为 780px，主要站点版心最大宽度为 1200px。正文通常为 15–16px，标题按页面层级响应式缩放；辅助信息保持次级对比度。

文章按标题、日期、正文的顺序组织；段落、列表和表格保持清楚的层次。正文标题使用真实的 HTML 标题结构，文章目录据此生成，目录只用于文章，不出现在作品详情。

间距以 4px 为基本单位，常用 8、12、16、20、24、32px。手机页面左右通常保留 20px，布局收纳优先于缩小文字和点击区域。

## 圆角层级

| 圆角 | 使用场景 |
| --- | --- |
| 6px | 提示气泡、试听标签、行内代码 |
| 12px | 筛选、目录条目、图标按钮、单曲封面 |
| 16px | 图片缩览、列表行、代码块 |
| 20px | 目录面板、播放器、提示块、折叠面板 |
| 24px | 主要卡片、作品入口、作品详情图片 |
| 胶囊 | 主要操作、返回、桌面导航 |
| 正圆 | 主题切换、联系图标等圆形热区 |

嵌套组件使用相邻的圆角层级，不让内层显得尖锐；音乐专辑封面有独立的圆角矩形样式。修改圆角优先使用 `--radius-*` 变量。

## 导航与响应式

电脑端导航直接展示主要入口；手机端使用菜单按钮展开覆盖层，不推挤正文。展开时使用透色毛玻璃材质与背景模糊，点击背景或按 Esc 收起。

首页、作品集、文章列表、相册簿和友链在同一窗口局部切换，保留全局播放器。作品与文章详情使用新标签打开；外部网站使用新标签并带 `noopener noreferrer`。

手机头像位于姓名右侧，介绍和操作按钮保留完整宽度。作品筛选由横向排列变为三列两行。首页作品缩览可横向滑动，右侧渐隐仅在还有内容未展示时出现。文章目录在小屏上收纳为浮层。

## 控件与反馈

主要按钮使用蓝色填充，次要按钮采用描边或轻表面。常规点击区域至少 44px，手机主要操作通常为 48px。图标按钮提供可访问名称；联系方式支持悬停提示与键盘焦点。

点击按钮时从触点扩散状态层。音乐卡片的选中颜色由实际播放状态控制，暂停或结束后恢复；按钮反馈不能代替真实状态。

代码块的复制按钮固定在右上角，不随代码水平滚动。点击后复制图标缩小，切换为同线条对钩并放大，再恢复复制图标。行内代码支持双击复制，气泡短距离上飘消失。

普通正文链接悬停时，从鼠标进入位置展开细下划线。按钮链接不使用正文下划线。

## 图片与相册

相册、文章、作品详情和首页头像共用大图预览。点击图片打开，滚轮缩放、左键按住拖动，点击实际图片外的空白或按 Esc 关闭。背景压暗并模糊，打开和关闭使用短暂过渡。

相册缩览有渐显入场、轻微放大与卡片抬升。文章与作品图片复用同一套预览过渡，避免不同页面出现不同操作习惯。用于跳转作品详情的封面仍保留导航功能。

## 动画规范

| 类型 | 参考时长 | 目的 |
| --- | --- | --- |
| 图标替换 | 130ms | 复制与状态切换 |
| 控件反馈 | 180ms | 快速表达响应 |
| 面板过渡 | 240ms | 说明浮层进入与退出 |
| 内容进入 | 约 400–500ms | 轻微渐显和位移 |

常规缓动为 `cubic-bezier(.2,0,0,1)`。目录、选项卡、折叠内容、图片预览都采用短过渡，动效不阻挡后续操作。浮层材质可显示瞬时触点光感。

音频有独立时序：播放和暂停淡变约 400ms；接近曲目结束时提前淡出，下一首再淡入。试听时长受实际音源限制。

系统开启“减少动态效果”后停用装饰动画，保留正常操作和状态表达。

## 材质与层级

正文和主要内容卡片保持清晰、稳定。实时模糊与透色集中用于导航、目录、播放器等浮层，使用浅边线和柔和阴影表达覆盖关系。手机导航背景遮罩为浅色 25% 白色、深色 25% 黑色，模糊为 8px。

播放器高于普通导航，图片预览进入浏览器模态顶层。所有浮层应保留明确的关闭路径，避免透明区域阻挡点击。

## 首页状态与操作反馈

首页状态使用 `profile.status` 的固定枚举：seeking（求职中／蓝）、available（开放合作／绿）、employed（在职／琥珀）、unavailable（暂不接单／灰）。方向文字由 `profile.specialty` 单独填写，颜色遵循全站语义变量。

反色鼠标圆形仅作用于普通文字，链接、按钮和其他交互控件不显示。主要按钮使用明显抬升与点触扩散；次要按钮使用浅色底、描边与轻微按压，不加环绕投影。控件投影优先使用强调色的低透明度阴影，背景遮罩仍按独立规范处理。

## 字体方案更新

全站界面与正文已统一为 **Noto Sans SC**，支持 100–900 可变字重；正文 400、控件 500、标题 600、强调 700。代码区域保留等宽字体，Logo 是矢量字标，不随正文换字体。

字体与授权保存在“网站管理/素材/fonts/noto-sans-sc/”。采用本地加载与 font-display:swap，不依赖用户访问 Google Fonts。现采用 WOFF2 Unicode 分包，浏览器仅下载页面实际用到的字符包；保留 font-display:swap，加载期间使用回退字体。

官方资料：[字重与元数据](https://github.com/google/fonts/blob/main/ofl/notosanssc/METADATA.pb) · [SIL OFL 授权](https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt)。

## 导航与联系方式图标

首页、作品集、文章、相册、友链及 QQ、微信、邮箱、电话统一使用 Remix Icon 官方线性图标，不再使用手绘路径。SVG 与授权文件集中在“网站管理/素材/icons/remix/”；图标使用 currentColor 遮罩，自动跟随深浅色与悬停颜色，保留原来的点击热区和提示。Logo 为独立个人标志，不属于这套功能图标。

来源：[Remix Icon 官方仓库](https://github.com/Remix-Design/RemixIcon)，授权随文件保存。

页脚统一使用 Noto Sans SC：电脑端主要信息 14px、字段名称 13px；手机端主要信息 13px、字段名称 12px。时间和版本数字使用等宽数字特性，不再另切换等宽字体。

播放列表采用约 180ms 渐显与 6px 位移，展开／收起均不改变播放器位置；系统减少动态效果时直接切换。

## 2026-11-17：跨页面交互规范

首页、作品、文章列表、相册、友链和网站收藏共用 `source/css/site-motion.css` 与 `source/js/site-motion.js`。这些文件在首页封面样式之后加载，负责统一交互；色彩、字体和圆角仍取自 `网站管理/设置/配色与外观.css` 的语义变量。

- 普通卡片使用相同方向的轻微鼠标倾斜与上浮，离开后平滑归位。只在鼠标活动时运行动画，不让全部卡片持续执行脚本。
- 文字链接使用从指针位置展开的细下划线；卡片标题和箭头提供一致的悬停反馈。键盘访问保留清晰的焦点轮廓。
- 常规反馈采用 160ms，卡片与链接过渡采用 280ms；首页封面保留用于展示的广角、漂浮和轮播，普通内容卡片不复制整套舞台效果。
- 手机触摸不启用依赖鼠标的倾斜；开启系统“减少动态效果”时关闭倾斜与多余过渡。
- 图片点击波纹以实际图片按钮为定位容器，受图片边界裁切；大图预览使用直角，完整展示图像边角。
- 首页导航与封面之间桌面端留 16px、手机端留 12px 间距，封面四角使用统一圆角，首屏高度扣除导航和这段间距。
- 封面右下角进入“网站收藏”，与“认识周城栋”的简历入口分工。

收藏卡片的图标使用网站自身的 favicon，下载、转成最多 64px 的 PNG 后从本站加载；获取不到时使用网站名称首字，不因缺图阻塞页面。首页收藏速览与完整收藏页共用同一个图标组件。

收藏卡片与友链卡片共用相同圆角、浅色提亮和柔和主题色阴影，轻微上浮并根据鼠标位置倾斜；卡片标题不额外加下划线。普通文字超链接统一沿用文章中的蓝色文字、从指针位置展开的 240ms 细下划线动画，不给整块卡片套文字链接效果。
`n高亮底纹与下划线动画互斥。卡片和胶囊按钮无下划线；纯文字链接展开下划线但不增加底纹。手机封面改用自适应高度、单列布局和收敛的卡片宽度，避免矮屏裁切。
