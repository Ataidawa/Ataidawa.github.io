# Jopolis 视觉规范

日常编辑入口：`网站管理/设置/配色与外观.css`，生成时自动同步到 `source/css/design-system.css`。`codex.css` 负责布局和交互的历史实现，最终配色与组件几何以此文件为准。新增组件使用语义变量，不另设相近颜色。

## 配色

| 用途 | 浅色 | 深色 | 变量 |
| --- | --- | --- | --- |
| 页面背景 | #F8FAFD | #1B1C1F | --bg |
| 卡片 | #FFFFFF | #23262B | --card |
| 次级表面 | #EDF2FA | #2B3038 | --surface |
| 主要文字 | #1F1F1F | #E3E3E3 | --ink |
| 次级文字 | #444746 | #C4C7C5 | --ink-soft |
| 辅助文字 | #5F6368 | #AEB3BB | --muted |
| 强调色 | #0B57D0 | #A8C7FA | --accent |
| 选中表面 | #D3E3FD | #304B75 | --selected |

成功、警告、错误使用 --success、--warning、--danger，始终搭配文字或图标。强调色上的文字用 --on-accent。文字选中颜色使用专门的 selection 变量。播放进度固定白色，保证封面上的辨识度。

## 圆角

| 大小 | 场景 |
| --- | --- |
| 6px | 提示气泡、试听标记、行内代码 |
| 12px | 筛选、目录条目、图标按钮、单曲封面 |
| 16px | 内层图片、列表行、代码块 |
| 20px | 目录、播放器、提示块、折叠面板 |
| 24px | 主要卡片、作品入口、作品详情图片 |
| 胶囊 / 正圆 | 主操作、导航 / 圆形图标热区 |

## 间距、交互与材质

间距以 4px 为基本单位；常用 8 / 12 / 16 / 20 / 24 / 32px。主要点触区域至少 44px，手机主要操作尽量 48px。

图标切换 130ms、控件反馈 180ms、面板过渡 240ms；常规缓动 cubic-bezier(.2,0,0,1)。音频淡变、进度及复制提示是特定交互，保留独立时序。减少动态效果时停用装饰动画。

实时模糊限定于导航、目录和播放器等浮层，正文保持清晰。保留不支持 backdrop-filter 时的背景回退。配色、圆角令牌与语义组件绑定集中在 design-system.css，避免新增覆盖规则分散在各处。
